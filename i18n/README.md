# Translating Korf Log and Korf Lab

Both apps are single HTML files. Every piece of text the user can see goes through a small runtime (`i18n/runtime.js`) that is embedded in each file. The English text in the code **is** the message key, so the code stays readable and English is always the fallback.

## Files

| File | What it is |
|---|---|
| `i18n/runtime.js` | `t()`, `th()`, `i18n.*` (embedded in both apps by the build) |
| `i18n/build.js` | Finds every message, checks the locales, embeds runtime and translations |
| `i18n/locales/<lang>.json` | One file per language: `{ "English message": "Translation" }` |
| `i18n/locales/<lang>.missing.txt` | Generated: messages that still need a translation |
| `i18n/messages.json` | Generated: every message, which app uses it and on which lines |

Add a language by adding `i18n/locales/<lang>.json` (e.g. `fr.json`), then add its button to the `.langsw` switch in both HTML files. Nothing else changes.

Build (from the repository root, safe to run repeatedly):

```
node i18n/build.js
```

It prints how many messages each language has, lists placeholder mismatches (exit code 1) and rewrites the embedded block in both HTML files.

## Writing messages in code

```js
i18n.t('Save backup')                                   // plain text
i18n.t('Step {n} of {total}', {n: 3, total: 6})         // named placeholders
i18n.t('{n, plural, one {# shot} other {# shots}}', {n: shots})   // plurals (ICU)
i18n.t('{side, select, H {Home} A {Away} other {Unknown}}', {side: 'H'})
i18n.t('Open', null, 'verb')                            // optional context for identical English words
i18n.th('Hello {name}', {name: userInput})              // for HTML: escapes the message and the values
i18n.th('Total: {html}', {html: i18n.html('<b>5</b>')}) // trusted markup must be marked
```

Rules that keep translators happy:

1. **One sentence = one message.** Never build a sentence from pieces (`'Found ' + n + ' shots'`). Use a placeholder.
2. **Never rely on word order or plural endings.** Use `{n, plural, ...}`. Dutch needs `one`/`other`; other languages may need more forms.
3. **Do not translate data.** Team names, league names, file names, CSV columns and saved data stay as they are. Exports are produced inside `i18n.asEnglish(function(){ ... })` so downloads are identical in every language.
4. Put the placeholder name to work: `{teamName}` tells the translator more than `{0}`.

### Tables of labels

Labels that live in a table at the top of the script are wrapped so they are translated when they are read:

```js
var CATS = i18n.labels({pass: 'Passes', shot: 'Shots'});   // CATS.pass is translated every time it is read
var WSTEPS = [[N_('Fixture'), N_('Which match is this?')]];  // N_() only marks a message for extraction
// ... later, where it is shown:
i18n.t(WSTEPS[0][0])
```

## Static markup

```html
<button data-i18n>Save backup</button>                         <!-- element text -->
<span data-i18n-html>Created by <b>Eric</b></span>              <!-- text with inline tags; the whole inner HTML is the message -->
<input data-i18n-attrs="placeholder title" placeholder="Search" title="Find a player">
<span data-i18n data-i18n-ctx="verb">Open</span>                <!-- context -->
```

Text that appears in CSS (`::after` content) is read from a CSS variable such as `--i18n-show`, which the runtime sets. The printed page footer ("Page 1 of 3") is generated by the runtime for the same reason.

## Language selection

`?lang=nl` in the address wins, then the choice saved in the browser (`korf_lang`), then the browser language. `?lang=pseudo` shows every translated string wrapped in `⟦ ⟧`, so anything not wrapped is still hard-coded. `?i18nlog` collects messages that are missing from the current language in `window.__i18nMissing`.

## Checking your work

* `node i18n/build.js` – missing messages and placeholder mismatches.
* Open an app with `?lang=pseudo` and click through it: text without `⟦ ⟧` has not been made translatable.
* Switch EN/NL while a match (Log) or files (Lab) are loaded: the screen must redraw in place and nothing may be lost.
